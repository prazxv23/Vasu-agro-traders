# Vasu Agro Traders – Service & Sales

Static mobile-friendly business website.

## Publish on Vercel
1. Create a GitHub repository and upload all files/folders in this project.
2. In Vercel, choose **Add New → Project**, import the GitHub repository.
3. Framework preset can be **Other**; no build command is required.
4. Deploy.
5. Optionally connect a custom domain later.
